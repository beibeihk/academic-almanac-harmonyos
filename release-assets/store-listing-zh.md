# AppGallery 发布文案

应用名称：学术黄历

英文名称：Academic Almanac

短描述：科研日签与离线工作台

完整介绍：

学术黄历是一款面向科研人员和高校学生的轻量趣味应用。首次使用选择所属学科门类后，每天根据日期在设备本地混合通用建议与学科专属文案，生成固定的科研“宜、忌、吉时与学术签”，第二天自动更新。支持哲学、经济学、法学、教育学、文学、历史学、理学、工学、农学、医学、管理学、军事学、艺术学和交叉学科。可在“关于”中修改选择。无需账号，无需联网，不读取科研文件。

四个功能页围绕科研日常形成完整流程：

1. 黄历：确定性每日宜忌、学术签与签文；月历浏览及日期跳转，收藏喜欢的日签；把“宜”一键加入科研计划。
2. 计划：按日期记录阅读、写作、代码、实验等目标；支持完成标记、全部/当日筛选、确认移除及带入专注。
3. 专注：15/25/45/60分钟计时，可暂停、继续和重置；完整完成的时段自动归档。未完成计时仅在本次运行内保存，不发送后台通知。
4. 回顾：查看七日计划完成与专注时长，按日保存回顾，重读或取消收藏。

计划、回顾、收藏与专注记录仅存储在本机，无账号、无服务器、无广告及第三方SDK；关于页可查看完整隐私政策并确认清除记录。

本应用不提供命理、占卜或真实择日功能。所有内容均为原创科研趣味文案，仅供娱乐，不构成任何学术、职业或其他决策建议。

版本更新说明：1.2.0 新增首次使用选择 14 个学科门类、560 条学科专属语料，日签混合通用与所选学科内容；可在“关于”中修改学科。新增独立 Android 兼容版，供 HarmonyOS 4.x 用户下载使用。两版均完全离线，应用间不提供自动数据迁移。

建议分类：教育 / 学习（如当前后台无匹配项，则选择实用工具）

关键词建议：科研，论文，研究生，博士生，学术，文献，写作，效率，日签

隐私摘要：完全离线；无账号；不收集或上传个人信息；无网络、位置、通讯录、照片权限；无广告和统计 SDK。
