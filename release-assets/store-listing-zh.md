# AppGallery 发布文案

应用名称：学术黄历

英文名称：Academic Almanac

短描述：科研人的每日宜忌，一款完全离线的学术趣味日签。

完整介绍：

学术黄历是一款面向科研人员和高校学生的轻量趣味应用。每天根据日期在设备本地生成固定的科研“宜、忌、吉时与学术签”，第二天自动更新。无需账号，无需联网，不读取科研文件。

从整理文献、保存代码，到回复审稿人、准备答辩，原创短文案记录科研生活里那些会心一笑的瞬间。首页为一屏式极简排版，适合直接截图分享。

本应用不提供命理、占卜或真实择日功能。所有内容均为原创科研趣味文案，仅供娱乐，不构成任何学术、职业或其他决策建议。

版本更新说明：首个公开测试版本；支持确定性每日内容、宜忌冲突过滤、吉时、学术签与离线隐私说明。

建议分类：教育 / 学习（如当前后台无匹配项，则选择实用工具）

关键词建议：科研，论文，研究生，博士生，学术，文献，写作，效率，日签

隐私摘要：完全离线；无账号；不收集或上传个人信息；无网络、位置、通讯录、照片权限；无广告和统计 SDK。
